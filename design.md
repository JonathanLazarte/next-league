# Design system

## Core color hierarchy

- Component surfaces and modal panels use `var(--blue-five)` as their base background.
- Titles generally use `var(--gold-one)`.
- Subtitles, supporting labels, and secondary copy generally use `var(--gold-three)`.

Use a different tone only when a component has a clear semantic state, such as an error, success, disabled control, or an interactive hover state.
